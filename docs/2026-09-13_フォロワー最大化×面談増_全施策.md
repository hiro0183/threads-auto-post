## 0. 結論（3行）

1. **投稿の質はもう主因ではない。「見られる → フォロー → 会話 → 問診」の変換が空。** 全期間で約300万views → フォロワー約900人（転換0.03%）。9月は263本出して、いいね16・読者返信4。直近では「手元の数字と照らせる話」が当たり始めている（4,188／1,863／1,129views）のに、フォロワーは+0.8人/週。
2. **効く順番は ①人間の存在（絡み・返信）②入口の整備（固定ポスト・bio・棚卸しシート）③計測の復活（LINE登録）④発見面（トピックタグ・画像）。** ①②③は今週着手できる。
3. **本数は減らさない。24枠の「役割」を組み替える。** 50→10→24と本数は3通り試して、どれもフォロワーを動かさなかった（実測）。動かしていないのは本数ではなく変換。

Codex（GPT-5.5）に同じデータを渡して独立に診断させた結論も同じ＝「いま必要なのは『もっと投稿を作る』ではなく、**伸びた投稿を入口に変える設計**」。

## 2. 伸びない原因（重要度順）

### 原因1: 変換の設計が空（最重要）
- 読者がプロフィールに来ても、**固定ポストが無く**、bioは「一人整体院14年」「院長へ」で治療院寄り（BNI経由の経営者には専門外に見える）。
- CTAは「無料の経営の問診（Zoom30分）」一択。**初見の読者にZoom30分は重い。** 途中の階段（軽い受け取り物・コメント・DM）が無い。
- 22:00のCTA枠は median 12。CTA自体が悪いのではなく、**症状を名指ししていない**（「経営の問診で見えます」は誰にも刺さらない）。

### 原因2: 人間がいない
- 全投稿が自動。**他アカへの返信0・自分の投稿への返信0**。読者にもアルゴにも「生きていない垢」に見える。
- 2026-07-13のガイドライン（`_ガイドライン_絡み方コメント周り`）で「唯一自動化しない人間の仕事」と定義したまま、**2ヶ月間、道具も習慣も作られなかった**。原因は意志ではなく、絡む相手を見つける手段（検索）が無いこと。

### 原因3: 到達エンジンの後継が細い
- 5〜6月の160万viewsは「スタッフ離職・廃業」の見物型（1万超え率6.0%）。8/4に廃止したのは正しい（創作・非読者）。
- 後継の「手元の数字と照らせる話」は当たり始めているが、**当たった投稿を再利用する仕組み（48時間後の派生・固定化）が無い**。

### 横断: 計測の空白
- views→フォロー→LINE→問診 のうち、**LINEから先が3ヶ月間空白**。どこで詰まっているかを断定できない状態で施策を積んでいた（Codexも「最大のボトルネックかもしれない」と指摘）。

## 4. 変換の算数（何を追うか）

```
問診 月2件（まず）
 ← LINE登録 週3人（問診転換20%仮置き → S5で実測に置換）
 ← コメント・DM 週5件（A1の「表」＋絡みからの流入）
 ← フォロワー純増 週+12人（現状+0.8）
 ← views は追わない（手段）
```

**4週間の目標（予測ではなく目標）:** フォロワー +50／読者返信 週5／LINE登録 週3／問診 月2。
**追う数字は2つだけ:** ①自分が出した返信の数（週25）②LINE登録数（週）。順番は「出した返信が先、登録が後」（BNIの「出した紹介が先」と同じ思想）。
