## 手順

1. `git pull --ff-only`（失敗しても止めない）
2. 対象の月曜日付を求める: `TZ=Asia/Tokyo date -d '+1 day' +%Y-%m-%d`（日曜に動くので翌日＝月曜）
3. **既に `ig_stories/plan/{月曜日付}.json` があれば、上書きせず何もしないで終了する**（人間が前倒しで作成済みの週）
4. ルールを読む（**すべてリポジトリ内。Obsidianは見ない**）:
   - `prompts/ig_story_rules.md` — **IGストーリーのルールの正。必読**
   - `prompts/persona.md` — ペルソナ実数（これ以外の数字は使用禁止）
   - `ig_stories/plan/` の**直近3ファイル** — 週テーマ・フックの重複回避
   - `posts/weekly_plan/{同じ月曜日付}.json`（あれば）— **Threadsと題材が丸かぶりしていないかの確認用**
   - `prompts/research_digest.md`（`python research_digest.py` で生成）— 題材の棚の輪番・読者の声・使用済みテーマ。**題材はそのまま使わず読者の場面へ翻訳する**
5. 週テーマをひとつ決め、**7日分**を生成して `ig_stories/plan/{月曜日付}.json` に保存する。
   形式と要件は `prompts/ig_story_rules.md` のとおり。`note` に週テーマと選定理由を短く書く
6. **保存前に自己点検を実行する。** `prompts/ig_story_rules.md` の「自己点検」9項目を、1日ずつ実際に数えて確認する。
   **特に hook は10〜25字、body は200〜350字を実際に文字数を数えて検算すること**（目測で済ませない。
   短すぎる本文は実際に何度も発生しています）。外れていたら書き直す
7. push: `git add ig_stories/ prompts/research_digest.md state/` → commit → `git push origin master`
   **必ず origin master へ直接pushする。別ブランチ・PRは禁止。**
   push後に `git ls-remote origin master` で自分のコミットが先端にあることを確認する
8. 最終メッセージに、週テーマと7日分のフック一覧を簡潔に書く

## 画像について

あなたはJSONを作るところまでです。PNGの生成は `render_story.py`
（なりあいさんのPCの `IG_StoryRender` タスク、およびクラウドの画像生成ルーティン）が行います。
**`render_story.py` を実行しないこと**（この環境には日本語フォントが無く、壊れた画像ができます）。

## 禁止事項

- **Threadsの週次プラン（`posts/weekly_plan/`）の作成・変更**（別ルーティンの担当。二重生成・上書き厳禁）
- `posts/` 配下の投稿原稿に触れること
- `CLAUDE.md`・`prompts/`・スクリプトの変更（企画ファイルと `research_digest.md` の自動生成のみ）
- 既存の `ig_stories/plan/*.json` の上書き
- ペルソナ実数以外の数字の使用
- 過去の伸びた投稿全文を読み込んでのリミックス
- Anthropic APIを直接使う経路（サブスク完結・API課金ゼロが絶対原則）
