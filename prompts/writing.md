## 0. この垢は何か

**紹介状です。集客エンジンではありません。**

BNIや1to1で会った社長が、その後で「この人に頼んでいいか」を確かめに来る場所。
週1回の定例会で顔を合わせた人が、帰ってから検索して開く。そのとき直近20投稿が名刺になります。

**だから追う数字は1つだけ。**「直近20投稿が、社長が読んで自分ごとにできる内容になっているか」。
views・フォロワー・エンゲージ率は追いません。月1回、なりあいさんが20投稿を見て判断します。

**この変更の理由（2026-09-18）:** 3ヶ月で720本/月を投じてフォロワーは+9人、LINE登録は月4人前後。
一方でBNIは週1回、生身の経営者20人以上と顔を合わせる場になった。売るものも
「整骨院の集客」から「社長を現場から解放する（1日2時間つくる）」に変わった。
入口がBNIに移った以上、Threadsは入口ではなく確認の場所として整える。

## 1. 誰に書くか

**BNIや1to1で実際に会った社長1人を思い浮かべて書きます。架空のペルソナは作りません。**

これがいちばん大事な変更です。架空の読者に向けて書くと、AIは空白を「それらしい因果」で埋めます。
実在の人に向けて書けば、知らないことは書けません。

**共通して持っている悩み:**
- 売上はある。でも自分が現場にいないと回らない
- 社員やスタッフに任せたいが、任せ方が分からない
- 数字を見る時間も、先のことを考える時間もない

**業種は問いません。** 治療院・クリニック・士業・小さな会社。
なりあいさん自身の整体院の話は「証拠」として使いますが、**向けて書く相手は社長です。**

**書かない相手:**
- 月商100万以下（投資の感覚がない・2026-08-31本人判断）
- 「売上が上がらない」と悩んでいる人（悩みの質が違う）

## 2. 何を書くか（背骨2本）

> **⚠️ 2026-09-18に差し替えました。** 旧背骨は「集客の3層」「売上の方程式」の2本でしたが、
> どちらも集客と売上の話で、いま売っている「社長の時間をつくる」とズレていました。
> 旧背骨は捨てずに §2-3「後段に置くもの」として残します。

### 背骨1: 手放す順番

**社長がやらなくていい仕事を、どの順番で手放すか。**

なりあいさんが実際にやったこと（`stories.md` A-10）が中核です。

- 広告を自分で打つのをやめて人に渡した
- リスティング広告は一切やめた。困ったことは何もなかった
- パソコンが苦手なまま、事務を月40時間ぶん手放した
- 施術中に電話に出ること自体が信頼を削る、という構造

**書き方の型:** 「何を手放したか」より「**どの順番で手放したか**」「**手放しても何も起きなかった**」。
社長がいちばん怖いのは「自分がやらないと回らなくなること」なので、そこに答える。

### 背骨2: つくった時間を何に使うか

**時間を作ること自体が目的ではない。作った時間で何をするか。**

ここになりあいさんの最大の実話があります（`stories.md` A-7）。

> **AIで時間を作ろうとしたら、売上が一度下がった。** PDCAが回らなくなったから。

これは「時間を作りましょう」という話の裏返しで、**作った時間の使い方を間違えた実話**です。
社長に刺さるのはこちらです。

使える素材:
- A-8 時間の使い方（時間のマトリックス／1日15分＝1日の1%／第2領域）
- A-9 経営の数字の見方（朝いちばんに見る数字／まずいと気づく指標＝新規／気づいてからの4ステップ）
- A-7 停滞と立て直し（時間を作ってPDCAが止まった話・希少性で立て直した）

**行き先:** 数字を見る → 先のことを考える → 目標を決める。
個人コンサル・目標設定・夢を描く、という商品の入口はここです。ただし**投稿では売りません**（§5）。

### 2-3. 後段に置くもの（旧背骨。捨てない）

**集客の3層**（見つけてもらう／信頼／次の一歩）と**売上の方程式**（客数×単価×リピート）は、
**手放した社長が次に見るもの**として本文の後段や、たまの1本に使います。
出典はなりあいさん自身のUPLINK講義台本（`materials/UPLINK_*`）で、質は高いままです。
主役ではなくなっただけです。

## 3. どう書くか

### 形

- **1本＝3連ツリー**（単体投稿は禁止。Threadsで単体は伸びない・旧taboo #3）
- 【1】フック20〜30字 →【2】中身 →【3】まとめ
- 週5本。月〜金。土日は出しません

### フック（【1】）の3つの掟

**掟1: 具体的な「物」を1つ置く。**

2026-09の実測で、上位の投稿は全部「物＋数字＋人の動作」でした。

| views | フック |
|--:|:--|
| 4,188 | 受付が急に休んだあの日から14年、院長が二度と繰り返さないと決めたこと |
| 1,863 | 35,000円の料金表に、院長が足している3行 |
| 1,129 | 固定費が月30万円を超えた院が、まず見直す1つの費目 |
| 1,038 | 問診票に、院長が足しておく3つの質問 |

使える「物」: 料金表・問診票・予約表・受付・回数券・前日連絡・固定費の費目・
朝いちばんに開く画面・スタッフへの引き継ぎメモ。
**抽象化すると死にます**（実測: SNS発信論0.4倍・紹介論0.3倍）。

**掟2: 本人の年数（14年・10年・7年目）に「理由」を付けない。**

`stories.md` にあるのは事実だけで、理由は書かれていません。
事実に理由を足した瞬間、架空の体験談になります。

- ✗ 「10年、300万を切らなかったのは**リピートの設計**」← そんな記録はない
- ○ 「3ヶ月で250万が320万になった院の共通点」← 三人称・理由は本文で回収
- ○ 事実だけ述べて、理由は【2】へ渡す

**掟3: 「院長」と書かない。**

2026-09-18のいちばん大事な変更です。旧ルールは読者が治療院の先生だったので「院長」で通じました。
**いまの読者は社長です。**「院長は〜」で始まると、読んだ社長が「自分向けではない」と判断して離れます。

- なりあいさん自身の話は **「僕」**、または主語を省く
  - ○「広告の管理画面を、僕はもう開いていません」
  - ○「広告費の振込先を、出稿から人に変えました」
- 三人称で書くときは **「社長」「ある会社」**
  - ○「現場から出られない社長が、最初に手放したもの」
- ✗「広告費の振込先を、院長は出稿から人へ変えました」← これが旧の書き方

**治療院の「物」は使ってよい**（料金表・予約表・問診票・受付）。
**物は具体的に、主語は僕か社長。** これを取り違えると、掟1を守っていても読者が変わりません。

**社長に通じない言葉は言い換える。**

| 使わない | 言い換え |
|:--|:--|
| サロンボード | 予約の管理画面 |
| 第2領域 | 重要だけれど急ぎではないこと |
| 患者様 | お客様（自分の院の話をするときだけ「患者様」でよい） |
| ホットペッパー | 集客の媒体 |

### 本文（【2】【3】）

- 骨格を毎回変える。**番号列挙（①②③）は週5本のうち2本まで**
- 疑問形で締めるのは週1本まで
- 「いかがでしたか」「〜してみてください」などのAI定型句は使わない
- 【3】は言い切って終わる。次の行動を1つだけ置く

### 書き出しの禁止リスト

これで始めない（実測の負けパターン）:
「実は」「知っていますか」「〜と思いませんか」「今日は〜についてお話しします」
「〜な人、いませんか」「衝撃の事実」

## 4. 使っていい数字と実話

**`stories.md` と `profile.md` に載っているものだけ。** 1つも足しません。

発信していい数字（`profile.md` §素材 の全在庫）:

| 数字 | 内容 |
|:--|:--|
| 47歳 | 本人の年齢 |
| 14年 | 一人整体院の年数 |
| 20分35,000円 | 現在の単価 |
| 15,000円 | 7年目ごろの単価 |
| 300円 | 開業〜3年目の窓口負担（※「保険」の語は出さない） |
| 300万 | 月商。言い方は「300を切ったことがない」 |
| 250万→320万 | クライアント実績（3ヶ月） |
| 月40時間 | 事務を手放した量 |
| 週休3日 / 10連休 | 休みの実績 |

**基準値は使えます**（2026-09-18で正式に認めました）。
「固定費が月30万円を超えた会社」「広告費5万円」のように、**読者の側の一般的な水準**として書くもの。
自分の実績として名乗らなければ、架空実績にはあたりません。1,129viewsの投稿がこの型です。

**使用禁止（確定）:** 8,500円／1,500円／46歳／「150から160」／250万→100万の失敗談
／450万・500万・850万（事実だが発信では使わない。300万に統一）

## 5. 絶対に破らない9つ

1. **`stories.md`・`profile.md` に無い数字と実話は書かない。** 1つでも創作したら全部疑われる
2. **事実に理由を足さない**（掟2）
3. **「保険」の語を出さない**（保険をやめた／保険から自費へ／保険の患者様、すべて）
4. **地名「辻堂」を出さない**
5. **単体投稿を出さない**（必ず3連）
6. **売り込みを本文に入れない。** CTAは週1本まで（金曜）。商品名・価格は一切書かない
7. **AIを主語にしたフックを書かない**（実測0.2倍）。AIは【3】の答え合わせに置く
8. **他人の不幸を見物させる型を使わない**（廃業した院長・最後の投稿を見た、等。
   `stories.md` に実話が無く創作になるため・2026-09-11廃止）
9. **同じ数字は月3回まで。同じ場面は月1回まで**（週5本＝月20本なので、これで足ります）

## 6. 月1回の作り方

**月の終わりに、翌月の20本（週5本×4週）をまとめて作ります。**

1. **なりあいさんが題材を選ぶ（30分）**
   - この1ヶ月のBNIや1to1で、社長から実際に出た困りごとを5つ書き出す
   - それが翌月の20本の骨になります。**ここが唯一の人間の仕事です**
2. **生成（Sonnet）**: 背骨1と背骨2から各10本。§3の掟と§5の禁止を守る
3. **機械検査**: ⚠️ **2026-09-18時点で、この2本は新しい形式を検査できていません。**
   `check_hooks.py` は旧の週次プラン（`days` 構造）を前提にしていて、無いと**何も見ずに正常終了**します。
   `check_body_style.py` も1日1枠では「最頻の骨格が100%」となり常にOKになります。
   **20本を1ファイルにまとめて検査する形への作り直しが宿題です（未着手）。**
   それまでは、§5 の9項目を人とHaikuが見るのが唯一の砦だと理解しておいてください
4. **独立検品（Haiku）**: 別セッションで§5の9項目だけを見る。生成側の意図は渡さない
5. **なりあいさんが20本を通して読む（15分）**: 「BNIで会った社長が読んで自分ごとにできるか」
6. `posts/YYYY-MM-DD.json` に1日1枠（07:30）で置く。土日は置かない

**なりあいさんの作業は月45分です。** 毎日・毎週の判断はありません。
