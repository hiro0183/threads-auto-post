# 院長の時間 棚卸しシート（リードマグネット）

Threads投稿で「コメントに『表』と書いてくれた方にお送りします」と案内し、DM/LINEでURLを渡す配布物。
目的は「無料の経営の問診」（Zoom30分）への入口を軽くすること。読者＝月商100万円以上・自費中心で、
売上は伸びているのに業務が多すぎて時間がない治療院の院長。

## 中身の要約（見出し構成）

1. **まずこれだけ**（3行）：足りないのは努力でも根性でもない／一番の詰まりは「自分がやった方が早いから」／だから書き出して分けるところから始める
2. **使い方 3ステップ**：①時刻つきで書き出す②残す・渡す・やめるに分ける③「渡す・やめる」から1つだけ選び期限を切る（「ノートは綺麗で〜」「1日15分は1%〜」の講義の言葉を1回だけ引用）
3. **シート本体**：時刻／やったこと／かかった時間／残す・渡す・やめる（○を付ける）／メモ　の記入欄10行
4. **「渡す」候補チェック**：一般的な候補20項目（☐付き・数字なし）
5. **僕の場合（実例）**：渡した／やめた／残した／決めた　の4項目
6. **次の一歩**：無料の経営の問診（Zoom30分・内容により最大60分）へのLINE導線
7. フッター：「ヒロ先生｜院長を現場から解放する仕掛け人」

## 使った実数・実話の一覧（指示書のリストからどれを使ったか）

- 一人整体院14年／47歳／単価35,000円（施術20分）／週休3日／月商は「300を切ったことがない」／今年の夏は10連休を取ったが売上は保てた
- もともとパソコンが苦手。事務を月40時間減らした（中身＝投稿の下書きと数字の分析が週3日・4〜5時間→30分〜1時間）
- 仕組みに任せたもの：予約リマインドの文章づくり／LINE返信の下書き／カルテ整理
- やめたこと：広告を自分で打つのをやめ、同じ予算で人に任せた／リスティング広告は一切やめた→「結果、困ったことは何もありませんでした」（金額は書いていない）
- 受付スタッフが急に休んだ日に施術中に自分で電話を取った実体験→「施術中に電話に出ること自体が信頼を削る」と決めた（件数なし・「スタッフはいた方がいい」という結論にはしていない）
- 経営を考える時間の取り方：朝の寝起き（一番コンディションのいい時間）
- 「1日15分は1日の1%。15分積めば1.01、サボれば0.99。365日で37.8倍の差」（講義の言葉・1回だけ使用）
- 「ノートは綺麗で気づきも多いのに成果が出ない人は、いつまでにやるという期限を切っていない」
- 「足りないのは、努力でも根性でもありません」「一番の詰まりは、たいてい『自分がやった方が早いから』です」
- 商品の約束：「1日2時間、院長の時間をつくる」／入口は「無料の経営の問診」（Zoom30分・内容により最大60分・売り込みはしません・「うちはまだ早い」も立派な答え）
- LINE登録リンク：`https://utage-system.com/line/open/QBooAfM2qWKZ?mtid=uVqmOIrsLg8j`

**指示書のリスト以外の数字・実績は使っていません。** 「渡す候補チェック」20項目は数字を伴わない一般的な業務名のみ。

## 生成できたファイル

- `tanaoroshi_sheet.html` — 単一HTML（CSS埋め込み・Google Fonts「Noto Sans JP」使用、フォールバックは Yu Gothic Medium / Meiryo / sans-serif）。`.page` 2枚構成で `@media print` によりA4縦2ページに収まる
- `tanaoroshi_sheet.pdf` — reportlab で直接生成したA4縦2ページのPDF（HTMLの見た目を再現、日本語フォントは Yu Gothic）
- `build_pdf.py` — PDFを再生成するスクリプト

## PDF化の手順

`reportlab` がインストール済みだったため、これを使ってPythonから直接PDFを生成した（HTML→PDF変換ではなく、同じ内容・同じデザイントーンでreportlabのPlatypus機能により組版）。`weasyprint` と `playwright` は未インストールで、HTMLをそのままレンダリングしてPDF化する経路は使っていない。

再生成する場合：

```
cd C:\Users\tujid\threads_tool\assets\lead_magnet
set PYTHONIOENCODING=utf-8
python build_pdf.py
```

日本語フォントは `C:\Windows\Fonts\YuGothR.ttc` / `YuGothM.ttc` / `YuGothB.ttc`（Yu Gothic）を `TTFont` で登録して使用。
チェックボックスは Unicode の `☐`(U+2610) が Yu Gothic に無く欠字（tofu）になったため、`□`(U+25A1 WHITE SQUARE) に置き換え済み（要注意点）。

HTML単体を手動でPDF化したい場合は、Edge/Chromeで `tanaoroshi_sheet.html` を開き「印刷 → PDFに保存」（用紙: A4・余白: デフォルト・背景のグラフィック: ON）でも同等の見た目になる。

## 配布時の注意

- LINE登録リンクは指示書に記載のURLをそのまま埋め込み済み。**現時点では差し替え不要**（公開ホスティングは行っていないため、HTML/PDFファイルをそのままDMで送るか、社内でPDFを画像化・ドライブ共有する運用を想定）。
- HTMLをWeb上に公開してURLで配布する場合は別途ホスティングが必要（このリポジトリには含まれていない）。
- 数字・実績・語句のルール（「保険」「業務効率化」等の禁止語、丁寧語、患者様表記、地名・院名なし）は指示書の絶対ルールに準拠済み。新しく文言を追加編集する際は同じ制約を必ず守ること。
